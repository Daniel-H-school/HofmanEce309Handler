# Put your P2 files here

Copy these four files from your **P3** repository (they are your P2 code):

| From your P3 repo | To |
|---|---|
| `include/core/conversation.h`     | `include/core/conversation.h` |
| `include/core/sentinel_scanner.h` | `include/core/sentinel_scanner.h` |
| `src/core/conversation.cpp`       | `src/core/conversation.cpp` |
| `src/core/sentinel_scanner.cpp`   | `src/core/sentinel_scanner.cpp` |

Do **not** copy `message.h`.

If your P2 code doesn't work, configure with `-DUSE_P2_REFERENCE=ON` to build against
`reference/p2/` instead. Say which one you used in your design log.
