# Put your P3 files here

Copy these four files from your P3 repository:

| From your P3 repo | To |
|---|---|
| `include/tools/tool_registry.h`   | `include/tools/tool_registry.h` |
| `src/tools/tool_registry.cpp`     | `src/tools/tool_registry.cpp` |
| `src/tools/workspace.cpp`         | `src/tools/workspace.cpp` |
| `src/tools/calculator_eval.cpp`   | `src/tools/calculator_eval.cpp` |

Your registry now holds 12 tools (P3's four plus the final project's eight).

If your P3 code doesn't work, configure with `-DUSE_P3_REFERENCE=ON` to build against
`reference/p3/` instead. Say which one you used in your design log.
