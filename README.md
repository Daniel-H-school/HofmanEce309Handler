# HofmanEce309Handler
This repository holds the class project for Daniel Hofman's ECE 309 AI Agent Handler Project.

Outside of the main Hofman_C++_Agent_Harness folder, you will see the files containing the C vibe coded harness from project 1.
  -vibe_coding_log.md holds the prompts and responses sent to AI agents
  -harness.c holds the vibe code for the Agent harness. It was created for the first project on 9/4/26
  -harness.h is its header
  -test_Harness.sh is a bash script designed by an AI Agent to test harness.c

Inside of Hofman_C++_Agent_Harness lies the main harness project. Within the tests and docs portions, individual project testing and documentation is given.
